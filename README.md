# El Mégane en MRUV

Ejercicio interactivo de Movimiento Rectilíneo Uniformemente Variado: un Renault Mégane 2000 rojo sale de Manuela Pedraza 6080 a las 21:30, parte del reposo con aceleración constante y llega al Garden Club (Pedro Morán 2379, CABA) a las 22:00.

- Recorrido real: ≈ 2.960 m (OpenStreetMap / OSRM)
- a ≈ 0,00183 m/s² · v final ≈ 11,8 km/h · v media ≈ 5,9 km/h

Incluye mapa animado, velocímetro, sonido de motor (Web Audio), gráficos x(t), v(t), a(t), cuestionario de 8 preguntas con respuesta y desarrollo y un laboratorio para cambiar los datos.

Es un único archivo: abrí `index.html` en el navegador.

Pensado para celular: barra de control fija abajo, botones grandes y ecuaciones que pasan de renglón.
